# TalkingFly — говорящая муха

Проект пропускает запах через упрощённую компьютерную модель мозга плодовой
мушки, восстанавливает по активности нейронов, что муха «понюхала», и
переводит это в человеческую фразу с помощью локальной языковой модели
(LLM).

```
запах → рецепторы мухи → модель мозга → декодер (нейросеть)
      → смысл запаха → LLM → фраза от лица мухи
```

Все звенья цепочки работают. Пример реального запуска:

```
truth: geraniol   (--sniffs 3 — запаха гераниола нет среди заученных)
мост: «лимонная корка среди веток сирени» [alpha-terpineol], ...
Муха: «Ммм, еда и дым меня манят.»
```

Декодер никогда не видел гераниола, но указал на его ближайшего химического
родственника — альфа-терпинеол («сирень, цитрус, хвоя»).

## Как это работает

У мухи есть клетки, которые первыми ловят молекулы запаха — **ORN**
(обонятельные рецепторные нейроны). Каждый тип рецепторов отвечает на свой
набор веществ, поэтому у каждого запаха есть характерный «отпечаток» — какие
рецепторы и насколько сильно он включает.

Проект делает следующее:

1. Берёт реальные измерения «какой запах какие рецепторы активирует» из базы
   **DoOR** (691 запах × 78 рецепторов дрозофилы).
2. Подаёт этот отпечаток как входной ток в симуляцию мозга: 3097 нейронов
   обонятельного участка, связи взяты из настоящей карты мозга **FlyWire**
   (полная карта всех соединений между нейронами, «коннектом»).
3. Симулирует 150 миллисекунд жизни мухи и записывает, сколько импульсов
   (**спайков**) выпустил каждый нейрон. Это «состояние мозга» — просто набор
   чисел.
4. Обучает **декодер** — нейросеть, которая по этому набору чисел определяет
   запах. Главная научная цель — чтобы декодер узнавал и **новые** запахи,
   которых не видел при обучении, то есть понимал химический смысл, а не
   зазубривал примеры.
5. Передаёт результат локальной LLM (gemma через llama.cpp), которая говорит
   короткую фразу от лица мухи.

Пустой воздух обрабатывается честно: ноль спайков — муха сообщает, что ничего
не чует, и не выдумывает запах.

## Словарик

| Термин | Что это |
|---|---|
| Дрозофила | плодовая мушка, классический модельный организм биологии; её карта мозга почти полностью отсканирована |
| Коннектом | полная карта связей «кто с кем соединён»; здесь — файл FlyWire FAFB v783 (16.8 млн связей, 138 тыс. нейронов) |
| ORN | обонятельный рецепторный нейрон, первая клетка на пути запаха |
| Гломерула | комочек, куда сходятся рецепторы одного типа; набор активных гломерул — «отпечаток» запаха |
| Спайк | короткий электрический импульс нейрона |
| LIF | простейшая модель нейрона: копит входящий ток, при превышении порога «стреляет» и сбрасывается |
| Brian2 | Python-библиотека для симуляции таких сетей |
| DoOR | открытая база «запах → реакция рецепторов» дрозофилы |
| Эмбеддинг | вектор-смысл: запись сущности (запаха, слова) списком чисел так, что похожие вещи получают близкие векторы |
| Декодер | нейросеть, восстанавливающая запах по активности мозга |
| Held-out | запахи, которые декодер при обучении не видел; проверка на понимание, а не на зазубривание |

## Результаты в цифрах

Канонический набор: 36 химически разведённых запахов × 20 прогонов +
10 пустых = 730 примеров.

**Знакомые запахи** (декодер видел их при обучении):

| Метод | Точность |
|---|---|
| Простейший поиск ближайшего примера | 96% |
| Реляционный контрастивный метод (лучший) | 83% |
| Линейная регрессия на гломерулах (используется в демо) | 79% (топ-3: 89%) |

**Незнакомые запахи** (held-out тест, 9 запахов вне обучения):

| Метрика | Значение | Случайное угадывание |
|---|---|---|
| Ранг правильного химического соседа | **6.5 из 27** | 13 |
| Попадание в топ-1 | 23% | 3.7% |
| Попадание в топ-3 | ~40% живых прогонов | 11% |

Вывод: модель устойчиво выше случая узнаёт химическое семейство нового
запаха, хотя точная идентификация пока не достигается.

**Устойчивость**: шум на входе и потеря до половины нейронов почти не влияют;
при наблюдении короче ~33 мс качество падает.

## Запуск

Требования: Windows, PowerShell, Python-окружение в `.venv` (менеджер пакетов
`uv`, обычного `pip` нет). Все команды запускаются через
`.\.venv\Scripts\python.exe <script>`.

### Шаг 1. Подготовить вход запаха (однократно)

```
.\.venv\Scripts\python.exe prepare_olfaction.py
```

Читает сырые CSV базы DoOR и аннотации нейронов, пишет готовые файлы в
`olfactory/`.

### Шаг 2. Проверка симуляции

```
.\.venv\Scripts\python.exe flynet.py --neurons 2000 --simtime 100
```

Базовый прогон модели без запахов; пишет `flynet_result.json`.

### Шаг 3. Запах вызывает состояние мозга

```
.\.venv\Scripts\python.exe run_odors.py --neurons 1500 --simtime 150 --gain 5
.\.venv\Scripts\python.exe analyze_odors.py
```

Строит подграф обонятельного участка, впрыскивает запахи в рецепторы, пишет
результаты в `results_odor/`. `analyze_odors.py` показывает, какие гломерулы
на какой запах отвечают.

### Шаг 4. Собрать датасет и обучить декодер

```
.\.venv\Scripts\python.exe build_odor_dataset.py --n-odors 36 --trials 20 `
    --drive-sigma 0.15 --gain 40 --delay-mean-ms 1.5 --delay-std-ms 0.5 --workers 8
```

Канонические настройки: сила сигнала `gain=40` и синаптические задержки
N(1.5, 0.5) мс — они дали лучший результат на незнакомых запахах. Без этих
флагов получится более слабый вариант. Сборка занимает ~3–4 минуты на 8 ядрах.

Проверки декодера (результаты пишутся в `decoder/*.json`):

```
.\.venv\Scripts\python.exe decoder_baseline.py     # линейный эталон
.\.venv\Scripts\python.exe decoder_ablation.py     # какие нейроны важны
.\.venv\Scripts\python.exe decoder_open.py         # распознавание новых запахов
.\.venv\Scripts\python.exe decoder_contrast.py     # контрастивное обучение
.\.venv\Scripts\python.exe decoder_robust.py       # устойчивость к шуму
```

> Примечание: `LinearSVC` из sklearn зависает на этих данных; в скриптах
> везде используется `SGDClassifier(loss="hinge")`.

### Шаг 5. Муха говорит

```
.\.venv\Scripts\python.exe stage5_fly_speaks.py                    # случайный запах
.\.venv\Scripts\python.exe stage5_fly_speaks.py --odor benzaldehyde
.\.venv\Scripts\python.exe stage5_fly_speaks.py --blank            # пустой воздух
.\.venv\Scripts\python.exe stage5_fly_speaks.py --list             # список 36 запахов
```

Полезные флаги:

| Флаг | Что делает |
|---|---|
| `--odor NAME` | конкретный запах (можно подстрокой); можно любой запах из базы DoOR, даже незнакомый декодеру |
| `--seed N` | воспроизводимый прогон |
| `--sniffs N` | усреднить N вдохов — снижает шум одиночной пробы |
| `--dataset-trial` | взять готовый пример из датасета вместо симуляции (мгновенно) |
| `--no-llm` | только декодирование, без фразы |
| `--bridge emb\|hyb` | альтернативные мосты, см. [ниже](#прямой-мост-мозг--llm) |
| `--shutdown` / `--keep-server` | остановить LLM-сервер / оставить его работать после прогона |

LLM-сервер (gemma-E2B через llama.cpp, порт 8765, около 2 ГБ памяти)
скрипт обслуживает автоматически: сам запускает, если тот не работает, и сам
останавливает, если запустил его для этого прогона.

### Шаг 6. Обучить прямые мосты мозг → эмбеддинг

```
.\.venv\Scripts\python.exe stage5b_brain_to_embedding.py            # первый запуск при необходимости сам перезапустит сервер
.\.venv\Scripts\python.exe stage5b_brain_to_embedding.py --offline  # повторный запуск без сервера
```

Всё работает локально: фразы сворачивает та же gemma через llama.cpp. Первый
запуск при необходимости перезапускает llama-server с флагом эмбеддингов. Пишет `decoder/text_embeddings.npy`, `decoder/bridge_emb.npz`
(обученная модель для шага 5) и отчёт `decoder/bridge_emb.json`.

## Муха говорит: примеры

Знакомый запах — бензальдегид (пахнет миндалём), свежая симуляция:

```
=== pipeline trace (fresh simulation) ===
truth: benzaldehyde   ORN spikes in window: 45456
decoder: benzaldehyde 98%, 1-hexanol 0%, 1-pentanol 0%
[смысл: пахнет как Цветочный, альдегидный, сладковатый.]

[декодировано: benzaldehyde 98%]
[муха думает...]

Муха: «Сладкая еда близко, надо лететь к ней.»
```

Незнакомый запах — эвгенол (гвоздика), его нет среди 36 заученных. Декодер
по построению может назвать только знакомые запахи, поэтому выбирает самого
похожого знакомого:

```
truth: eugenol   ORN spikes in window: 45051
decoder: 2-methoxy-4-vinyl phenol 93%, methyl salicylate 3%, ...

Муха: «Сладкая, едкая, много всего в воздухе!»
```

Выбор осмысленный: 2-метокси-4-винилфенол — почти близнец эвгенола (то же
метоксифенольное ядро), тот же ряд «гвоздика и дым». Модель распознала
химическое семейство.

Пустой воздух:

```
truth: __blank__   ORN spikes in window: 0

[пустой воздух]
Муха: «Скучно, иду по воздуху без цели.»
```

Сводка живых прогонов:

| Что нюхали | Знакомый? | Декодер сказал | Уверенность | Вердикт |
|---|---|---|---|---|
| бензальдегид (миндаль) | да | benzaldehyde | 98% | точно |
| альфа-терпинеол (сирень) | да | alpha-terpineol | 88% | точно |
| пустой воздух | — | тишина | — | корректно |
| эвгенол (гвоздика) | **нет** | 2-methoxy-4-vinyl phenol | 93% | почти близнец |
| гераниол (роза) | **нет** | alpha-terpineol | 65% | хим. сосед №1 |
| ацетофенон | **нет** | methyl benzoate | 53% | хим. сосед №2 |

## Прямой мост мозг → LLM

Классический вариант (шаг 5) сначала угадывает **имя** запаха и дальше
опирается на знания LLM. Проект также исследует изначальную идею — проецировать
состояние мозга сразу в смысловое пространство LLM, без этапа называния:

```
мозг → декодер → эмбеддинг → текст
```

Идея реализована в двух вариантах (`stage5b_brain_to_embedding.py`,
включается флагом `--bridge`):

| Вариант | Цепочка | Знакомые запахи | Незнакомые запахи |
|---|---|---|---|
| `name` (по умолч.) | мозг → имя → знания LLM | 79% | топ-3 соседей ~40% |
| `emb` — прямой | мозг → точка в пространстве текстовых смыслов → ближайшие фразы | **94%** | уровень случайности |
| `hyb` — гибридный | мозг → предсказанный химический профиль → смесь смыслов похожих запахов | 79% | **ранг цели 6.4 из 35** (случай: 17.5) |

Как устроены прямые варианты. Для каждого запаха написаны короткие фразы о
том, чем он пахнет в жизни («миндальное печенье», «костровый дым»). Эти фразы
сворачиваются той же локальной моделью в эмбеддинги. Далее обучается
регрессия: состояние мозга → точка в этом пространстве фраз. В промпт мухи
идут ближайшие фразы-«оттенки» — **химические названия не используются
вообще**.

Главный вывод этого этапа: **чисто прямой путь не переносится на незнакомые
запахи**, потому что бытовые описания в эмбеддингах языка почти ортогональны
химии (корреляция между языковой и химической близостью запахов — 0.02).
Язык передаёт «стиль» запаха, но не структуру рецепторных ответов. Поэтому
гибридный вариант (`hyb`) для незнакомых запахов сначала предсказывает
химический профиль (он-то обобщается, см. таблицу результатов), а уже потом
переводит его в человеческие оттенки смысла.

Флаг `--sniffs N` усредняет N вдохов — аналог того, как настоящая муха
сэмплирует пахнущий шлейф во времени. Одиночная проба шумит; например,
гераниол стабильно указывает на сирень/терпинеол только начиная с трёх
вдохов.

## Что выяснилось

1. **Запах реально различим в активности нейронов.** Уже простой линейный
   декодер угадывает знакомый запах в 79–96% случаев. Основную информацию
   несут сами рецепторные нейроны (ORN).

2. **Сила сигнала критична.** При слабом входе (gain=5) запахи плохо
   разделены; рабочее значение — gain=40.

3. **Синаптические задержки — самый сильный рычаг.** Индивидуальные задержки
   ~1.5 мс ломают синхронную «пушку» нейронов: разные пути дают разные
   временные узоры, и сеть начинает именно *различать* похожие запахи. Ранг
   правильного ответа на незнакомых запахах улучшился вдвое (10 → 6.5).

4. **Реляционное контрастивное обучение — лучший метод декодера.** Идея: учить
   вложения так, чтобы близость векторов равнялась химической близости
   запахов. Именно этот метод даёт обобщение на новые запахи (таблица выше).

5. **Незнакомые запахи: важно ставить тест честно.** На плотном облаке из 240
   взаимно похожих запахов декодер выглядит «на уровне случайности» — но и
   идеальные данные (истинный химический профиль без всякого мозга) дают там
   то же самое: у каждого запаха десятки почти одинаковых соседей, и задача
   «найди единственного ближайшего» некорректна. На химически разведённом
   наборе из 36 запахов мозг уверенно несёт химическую идентичность.

6. **Языковое пространство не переносит химию.** Бытовые описания запахов в
   эмбеддингах LLM согласованы с рецепторными данными лишь на 2%. Отсюда
   практический вывод: для новых запахов смысл лучше проводить через
   химический профиль, а не напрямую через язык (см. раздел про мосты).

7. **Пустые пробы молчат — это норма.** В модели нет спонтанного шума, поэтому
   отсутствие запаха означает ноль спайков. Декодер использует отдельный
   детектор тишины.

## Ограничения и подводные камни

**Научные упрощения модели**

- Нейроны моделируются упрощённо (LIF), обонятельный участок взят изолированно
  — без грибовидных тел и других отделов. Абсолютные цифры не следует
  экстраполировать на настоящий мозг.
- В модели нет спонтанной активности и шума, поэтому «тишина» абсолютна.
- 36 запахов набора выбраны химически разведёнными; на плотных облаках похожих
  веществ задача требует другой метрики (см. пункт 5 выше).

**Технические ограничения**

- Версия numpy зафиксирована на 1.26.4: Brian2 2.8.0 несовместим с numpy 2.x.
  Обновлять numpy в окружении нельзя.
- Симуляция выполняется на CPU. GPU-бэкенд brian2cuda не поддерживает
  Windows нативно (для него требуется WSL2 или Linux).
- Формат генератора датасета не совместим с `cpp_standalone` (несколько
  прогонов на сборку и большой табличный входной сигнал); используется
  CPU-параллелизм через `--workers`.
- CSV базы DoOR экспортированы из R: разделитель — точка с запятой, поля в
  кавычках, много пустых значений. Аннотации нейронов — TSV.
- `proofread_connections_783.feather` (карта мозга, 852 МБ) — входной файл,
  предназначен только для чтения.
