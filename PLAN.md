# Talking Fly — план проекта

**Идея:** система, которая получает запах, пропускает его через модель мозга
дрозофилы (FlyWire FAFB v783 + Brian2), затем переводит состояние мозга в
понятный LLM «смысл», чтобы LLM мог «рассказать», что муха почувствовала.

**Главная цель первого рабочего прототипа:**
`запах → модель мозга → определить запах`.
Текст и LLM добавляются только после того, как этот цикл заработает.

## Этапы

### 1. Запустить мозг
- [x] Взять связи из FlyWire FAFB v783 (`proofread_connections_783.feather`).
- [x] Прогнать подграф нейронов через Brian2 (LIF на CPU).
- [x] Добиться стабильной работы без реального входа (I_drive на 1/3 нейронов).

### 2. Добавить обоняние
- [x] Найти в аннотациях FlyWire обонятельные рецепторные нейроны (ORNs):
      `flywire_neuron_annotations.tsv` (flyconnectome/flywire_annotations),
      все 2277 ORN есть в коннектоме (53 типа по гломерулам).
- [x] Взять реальные данные реакции ORN на запахи: база DoOR
      (`door_response_matrix.csv`, 691 запах x 78 рецепторов) + карта
      `door_mappings.csv` гломерула -> рецептор. Покрыто 47/53 типов.
- [x] Преобразовать реакцию на запах в сигналы входа:
      `prepare_olfaction.py` генерирует `olfactory/orn_table.csv`,
      `resp_matrix.npy`, `odor_names.json`; функция `stimulus(odor)`
      даёт per-ORN ток возбуждения (пА). Демо различимости: `demo_odors.py`.

### 3. Получить реакцию мозга
- [x] Запускать модель для разных запахов: `run_odors.py` строит AL-подграф
      (top-K пресинаптические AL-нейроны + все 2277 ORN), гонит ORN током
      `base + gain*ответ_DoOR`, прогоны по 6 запахам + blank за ~8 c.
- [x] Сохранять активность нейронов во времени: `results_odor/spikes_*_t.npy`
      (времена), `spikes_*_i.npy` (индексы), `states.npy` (счётчики спайков
      в окне стимула), `neurons.csv` (root_id/ORN/тип), `summary.json`.
- [x] Проверить, различаются ли состояния мозга: средний попарный косинус
      векторов активности < 1 — ORN 0.55, все нейроны 0.79, non-ORN 0.82;
      похожие эфиры (этил-ацетат/этил-бутират) дают близкие состояния.
      Blank молчит — в модели нет спонтанной активности (без шума LIF с DC
      выше порога насыщается, ниже — тихий). Анализ: `analyze_odors.py`.

### 4. Сделать декодер
Самый важный этап. От «запахи различимы» к «по состоянию мозга восстанавливаем
запах» — и затем мост в LLM. Разбит на 6 подшагов.

#### 4.1 Данные: расширить датасет состояний
Сейчас 1 прогон на запах и 6 запахов — нечего учить.
- [x] Повторные прогоны с шумом/вариацией: `build_odor_dataset.py` гонит
      `--trials 20` на запах с trial-to-trial джиттером драйва `--drive-sigma
      0.15` (intra-trial корр 0.66–0.81). Итог: 730 триалов (36 запахов x 20
      + 10 blank), сборка ~6 мин.
- [x] Расширить набор запахов с 6 до десятков: отбор 36 из 691 DoOR.
      Важно: отбор фильтрует запахи по реальной активации наших ORN
      (`min_active` орнов с ответом >= 0.3) — иначе запах неотличим от blank
      (норма состояния 0).
- [x] Зафиксировать признаковое представление «состояния мозга»:
      `decoder/dataset.npz` хранит X_counts (730 x 3097, спайки за окно),
      X_bins (7 бинов), X_glom (53 гломерулы + "other"), X_glom_bins;
      метки y 0..36 (blank — отдельный класс), `odor_names.json`,
      root_ids/is_orn/group_ids, `meta.json` с параметрами.
- [~] Нормализация (L2/z-score) и работа с разреженностью: blank уходит в
      отдельный класс; нормализация (z-score по нейронам) делается на этапе
      обучения декодера (4.2) по train-подвыборке, чтобы не было утечки
      статистики из теста.

#### 4.2 Бейзлайн-декодер (сначала простое, потом сети)
- [x] Логистическая регрессия / линейный SVM на состояниях — эталон.
      `decoder_baseline.py` (linear_svm = SGDClassifier(hinge)). Важно:
      `LinearSVC` из sklearn **зависает** на этих данных — заменён на SGD.
- [x] Корректное разделение train/test ПО ЗАПАХАМ (stratified trial split
      внутри одного набора + отдельный held-out-тест на невиденных запахах).
- [x] Метрики: accuracy / top-k recall, сравнение со случайным (1/37≈2.7%).
- [~] Результат (честный): **closed-set выше случайного** (acc@1≈0.21,
      acc@3≈0.42; blank отделяется на 100%), но **held-out (9 невиденных
      запахов) — на уровне случая** (hit@1≈0.03 при chance 0.037). Закрытый
      линейный классификатор запоминает конкретные запахи, не учит
      непрерывное пространство запахов.

#### 4.3 Абляции (насколько «мозг» нужен вообще)
- [x] Декод на ORN, non-ORN и всём (`decoder_ablation.py`).
      **Вывод:** ORN в одиночку декодирует лучше всего (acc@1=0.235),
      non-ORN хуже (0.155), гломерульная агрегация — хуже всего (0.137).
      В линейном closed-set режиме downstream-цепочка AL не добавляет
      пользы сверх «сырого» ORN-входа.
- [ ] Устойчивость (шум / пропажа нейронов / укорочение окна) — не делалось.

#### 4.4 Нейросетевой декодер
- [x] MLP (128,64) на прогонах 4.1: closed-set acc@1≈0.168 — **хуже линейного
      бейзлайна** (переобучение на малых данных).
- [x] Открытый набор: регрессия brain→эмбеддинг запаха (Ridge и MLP) для
      невиденных запахов. Предсказанный эмбеддинг коррелирует с ИСТИННЫМ
      эмбеддингом невиденного запаха лишь cos≈0.20–0.23 при потолке
      (true vs ближайший seen) ≈0.575. **Генерализация пока не достигнута.**

#### 4.5 Мост в эмбеддинги LLM
- [x] Пайплайн маппинга brain→эмбеддинг реализован в `decoder_open.py`:
      целевой эмбеддинг = PCA(30) пространство DoOR-рецепторных ответов
      (это и есть «смысл» запаха для мухи). Если положить
      `decoder/text_embeddings.npy` (n_odors × dim, в порядке odor_names.json)
      — используется ВМЕСТО DoOR (drop-in для реальных LLM-эмбеддингов).
- [~] Семантическая ближесть для невиденных запахов пока **не** согласуется с
      химическим сходством (см. 4.4): маппинг не генерализует на held-out.
      На ИЗВЕСТНЫХ запахах маппинг обучается (brain→эмбеддинг сходится), но
      критерий «генерализация на удержанные» не выполнен.

#### 4.6 Критерий готовности для этапа 5
- [~] Классификация удержанных запахов значимо выше случайного — **ЧАСТИЧНО**:
       см. 4.7 (после трёх рычагов held-out retrieval выше случая, но слабо:
       mean_rank ~10–11 из 27 при случайном ~13; hit@1≈0.13–0.15 при chance 0.037).
- [~] Маппинг в эмбеддинги работает на известных запахах, но не генерализует
       на held-out (4.5).
- [x] Артефакты зафиксированы: `decoder/dataset.npz`, `baseline.json`,
       `ablation.json`, `open.json`, `meta.json`, `odor_names.json`.
- [x] Применены три рычага улучшения (4.7): сильнее драйв (gain 5→40),
       временные признаки (X_traj), контрастивное обучение. Барьер пробит
       частично — остаток упирается в перекрытие состояний мозга (min corr 0.78)
       и тонический драйв. Следующий шаг — **нестационарный (импульсный) ORN-драйв**
       для богатой динамики + сильнее ORN→AL-трансформация.

#### 4.7 Три рычага: драйв / временные признаки / контрастивное обучение
Проверка гипотез из обсуждения. Все замеры на 36 запахах (730 триалов),
held-out = 9 запахов (every 4th), генерализация мерится как «ближайший seen-запах
в эмбеддинге — химически (DoOR) похожий ли?». chance@1=0.037, случайный mean_rank≈13.

- **Рычаг 3 — сила драйва.** Свимп gain ∈ {5,10,20,40} при base=1.0:
  min попарный корр состояний падает 0.921→0.900→0.921→**0.872** (gain=40 лучший);
  повышение base не помогает (0.919 при base=1.5). Регенерация датасета при gain=40
  (build_odor_dataset.py, теперь пишет и X_traj — 30 бинов по всему окну):
  min corr **0.778**, intra-trial корр 0.7–0.86 (воспроизводимость сохранена).
  Этот же датасет поднял closed-set логрег с 0.21 до **0.57** acc@1 — рычаг 3
  реально работает.
- **Рычаг 1 — контрастивное обучение.** Наивный InfoNCE («одинаковый=близко,
  разный=далеко») обучается (loss 0.074→0.044), closed-set 1-NN 0.68, НО held-out
  mean_rank **ухудшается** (12.0 vs 11.0 у raw PCA): равномерно раскидывает запахи
  и стирает химическую структуру. Фикс — **relational contrastive**: цель =
  inner-product эмбеддингов == DoOR-корреляция пар запахов (decoder_contrast.py,
  train_relational). Он даёт лучший held-out mean_rank **10.3** (X_counts) и
  **10.9** (X_traj) — выше raw PCA и plain contrastive. То есть именно
  «химически похожие = близко», а не «одинаковые = близко», — ключ к unseen.
- **Рычаг 2 — временные признаки (X_traj).** Полнооконный PSTH (30 бинов, 5 мс)
  захватывает onset/offset-транзиенты. На held-out он НЕ помог (mean_rank 10.9–11.3
  — на уровне или чуть хуже X_counts 10.3–11.0): при тоническом драйве динамика
  плоская, сигнал несёт сумма спайков, а не форма. Рычаг 2 эффективен только при
  **нестационарном драйве** (см. следующий шаг).

- **Итог (held-out retrieval, лучшее по каждой модальности):** X_counts
  relational mean_rank=10.3 / hit@1=0.15; X_traj relational mean_rank=10.9 /
  hit@1=0.11. Все выше случая, но скромно — фундаментальный потолок = перекрытие
  состояний (min corr 0.78) и грубый тонический драйв. Артефакт: `decoder/contrast.json`.
- **Следующий шаг (не сделано):** нестационарный ORN-драйв (TimedArray-импульс)
  → богатая PSTH-динамика → рычаг 2 заработает; + relational contrastive как
  целевая функция. Это главный оставшийся рычаг для пробития барьера 4.6.

### 5. Подключить LLM
- [ ] `запах → мозг мухи → decoder → embedding → LLM`
- [ ] LLM генерирует фразу от лица мухи.

## Технический контекст
- Окружение: Windows, `.venv` (Python 3.11.9, brian2 2.8.0, numpy 1.26.4,
  pyarrow, pandas).
- GPU (brian2cuda) отложен — на нативной Windows не работает, нужен WSL2/Linux.
- Текущий файл: `flynet.py` (LIF: tau=10ms, Vt=-50mV, Vr=-65mV, tau_syn=2ms,
  dt=0.1ms; знак веса из transmitter-профиля gaba vs glut).
